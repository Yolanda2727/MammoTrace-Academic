# Ejemplos exclusivamente sintéticos

Las imágenes son fantomas generados por `mammotrace/phantom.py`. No son mamografías de pacientes. Las categorías de los textos ficticios **no son etiquetas de los fantomas**. Su asociación existe para probar la carga y los flujos de la aplicación.

Hay ocho escenarios con PNG y TXT; ED03 está además disponible en DICOM, TIFF de 16 bits, JPEG, BMP y WebP. Su informe ficticio se ofrece en PDF y DOCX para comprobar lectores. ED04 incluye una guía PDF generada por el motor educativo como resultado de ejemplo.

`EJEMPLO_METRICAS_SINTETICAS.csv` contiene etiquetas y puntuaciones artificiales para enseñar cálculo de métricas. No es resultado del modelo original y no demuestra rendimiento clínico. `escenarios_ficticios.json` documenta los datos declarados y el nivel educativo esperado.
